---
name: Analytics ownership
description: The user's scope boundary for Google Analytics and Google Tag Manager configuration.
---

Do not change the existing Google Analytics or Google Tag Manager setup unless the user asks.

**Why:** the user set up GA and GTM themselves and explicitly asked that their setup not be touched.

**How to apply:** keep changes to analytics integrations and tag configuration out of unrelated feature work. Ask before making a change that would alter the existing setup.
